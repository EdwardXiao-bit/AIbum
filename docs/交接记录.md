## 重要实现与修复

- 官方模型无现成 safetensors：脚本安全加载官方 bin 后转换，固定官方 revision。
- Transformers 4.57.6 get_text_features 调用了禁用 pooler：使用官方 forward 一致的 CLS 投影。
- 前端表单 reset 按钮遮蔽原生方法：已改名。
- 人工标签清空后被重新生成：通过 tags_edited 保留人工决定。
- 去重/容量及后台任务领取使用立即事务，避免并发竞争；分析完成仅更新仍为 processing 的记录。
- 标签使用最高分差距限制，避免强行补足三个标签。仍需真实样本校准。

## 文件和启动

- 正式数据为 `data/`；浏览器验收为 `tmp/browser-data/`；示例为 `tmp/samples/`。不要混用。
- `.venv/`、`models/`、数据、原始论文和需求全文均不入 Git。用户原始 doc/zip 未修改。
- 启动：`.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`，或 `./start.ps1`。
- 授予管理员：`.\.venv\Scripts\python.exe scripts\manage.py make-admin 用户名`。
- 当前单进程，不要添加多 worker 参数。
